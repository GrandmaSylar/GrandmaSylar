## Current Work — CUA National Service (2025–2026)

At the Ghana Cooperative Credit Unions Association, I have:

- Deployed and configured QSS Core Banking backend systems on Linux VPS servers with Nginx, SSL, PM2, Docker, and DNS configuration
- Built **easyMigrate**, a Node.js ETL tool used to clean and migrate financial records for credit union clients with 99.53% reconciliation accuracy
- Led production MSSQL database disaster recovery by tracing backup files through Docker overlay filesystem structures
- Designed an automated daily backup system using bash scripting, cron jobs, and Docker container integration
- Reconciled 448 mobile banker transactions against 1,792 member records and produced structured audit reports
- Delivered end-user training on QSS Core Banking software to client institution staff
